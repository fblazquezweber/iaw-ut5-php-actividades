# iaw-ut5-php-actividades

Proyecto realizado en PHP para la UT5 de Implantación de Aplicaciones Web.  
Incluye tres actividades prácticas desarrolladas en local y probadas con Laragon.

## Tecnologías utilizadas

- HTML5
- Bootstrap 5
- PHP
- Laragon
- Git y GitHub
